## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

The string is traversed from the last character to the first character. Each character is printed in reverse order to produce the reversed string.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

A single-character string is already reversed, so the output remains the same.
